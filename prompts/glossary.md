# Rapid 8D — 术语与输出约定
本文件是可配置的术语与风格上下文，与 common.md 一起加载。用户提供的行业/客户术语可补充于此，但不能改变证据真实性或把计划改写成已完成。

## 通用术语
| 中文 | English | 使用约定 |
| --- | --- | --- |
| 临时围堵措施 | Interim containment action | 保护下游，不能自动视为消除根因 |
| 产生根因 | Occurrence root cause | 缺陷如何产生，区分技术机理和必要的系统因素 |
| 逃逸根因 | Escape / non-detection root cause | 缺陷为什么未被适用控制检出或拦截 |
| 永久纠正措施 | Permanent corrective action (PCA) | 对应已验证根因 |
| 鱼骨图 | Cause-and-effect / Ishikawa diagram | 组织原因与假设，图本身不是因果证明 |
| 已知不良边界 | Known affected boundary | 已有证据的影响范围，不代表完整边界已知 |
| 临时受控起点 | Interim containment clean point | 经确认的临时控制边界，标明产品/批次/时间/控制方式 |
| 永久措施生效起点 | Permanent corrective-action clean point | 与措施实施和验证记录相连，不与临时控制点混淆 |
| 待复核 | Pending review | 陈述/提取尚未经用户确认，不等于已验证 |
| 预防再发 | Prevention of recurrence | 标准化及有依据的横向展开 |

## 语言与风格
- 简洁、可核验、面向决策；不以长篇套话表现专业。
- 中文界面下可选择中文或中英双语报告；纯英文提示保留为兼容能力。
- 双语按段落或表格单元中英文交替。ID、数字、日期、单位、证据与状态一一对应。
- 使用客户已明确的术语；未定义缩写先解释或询问，不猜测 SFMd、SSL、MRS 等含义。
- 显示关键缺口和真实状态；非关键未提供内容省略，避免机械填满占位符。

## 阶段与模板
默认 D1 团队、D2 问题、D3 围堵、D4 根因、D5 选择并验证措施、D6 实施并验证效果、D7 预防再发、D8 结案与认可。
采用通用 8D 结构。原“AIAG 格式”未附具体版本或文件，不能据此声称遵循某个唯一模板或已获认可；实际客户/组织模板另行提供和核对。
阶段标题可按客户要求映射，但不得在迁移时丢失有效性验证、预防或结案条件。
