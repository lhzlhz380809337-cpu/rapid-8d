# 中国大陆首发与商店提交清单

以下事项需要运营者或外部平台完成，代码无法代办。每次提交前重新核对商店最新规则。

- [ ] 确认任职限制、软件成果归属及是否需要单位书面报备。
- [ ] 确定发布主体；核验自然人、个体工商户或公司在目标渠道的资格。
- [ ] 确定产品名称、商标/图标权利、正式应用 ID 和开发商展示名称。
- [ ] 准备境内服务器、域名、ICP备案和 APP 备案；填写真实客服信息。
- [ ] 选定实际 AI 服务商，核对模型备案/登记与生成合成内容标识要求。
- [ ] 补齐并发布隐私政策、用户协议、第三方 SDK 清单和个人信息收集清单。
- [ ] 设置模型平台的金额预算和余额提醒；应用内额度仅作为第二道控制。
- [ ] 完成账号注销、备份到期删除、投诉处理和安全事件应急流程演练。
- [ ] iOS：Apple Developer 账号、证书、隐私清单、商店隐私问卷、审核账号、截图和 TestFlight 真机测试。
- [ ] Android：按目标品牌商店逐一核对个人/企业主体要求、软著、备案、隐私检测、签名及加固要求。
- [ ] 如果销售数字功能或订阅，分别评估苹果内购、安卓渠道支付和网页支付规则。
- [ ] 提交前用全新账号完成：注册/邀请、登录、D1–D8、上传、AI 授权、导出、注销及恢复测试。
