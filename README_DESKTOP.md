# Rapid 8D Windows 桌面版 0.3.1

用于个人完成制造业 8D 调查、整理报告。首版有两种入口，最终进入同一案例工作区。

## 安装和启动

最简单的方式：双击项目最外层的 **启动 Rapid 8D.exe**。启动时会显示品牌载入画面，然后自动查找便携版或当前账户下的安装版。

双击 release/Rapid8D-Setup.exe，点击“安装”。安装在当前 Windows 用户的 LocalAppData/Programs/Rapid8D，并创建桌面和开始菜单快捷方式，不需要另外安装 Python。

便携版可双击 release/Rapid8D/Launch Rapid 8D.exe。移动便携版时，请移动整个 Rapid8D 文件夹，保留旁边的 _internal 文件夹。

面向 Windows 10/11 64 位，使用本机 Edge 或 Chrome 的独立窗口；没有这两者时尝试默认浏览器。当前实测为本机 Windows 环境，尚未覆盖所有 Windows 版本。应用包含本地运行环境，不包含另一套浏览器。0.3.1 安装包约 21 MB，解压后的程序约 43 MB；新版不再创建独立浏览器配置，并会清理旧版遗留的浏览器缓存，避免数据目录膨胀到数百 MB。点击窗口右上角“×”后，Rapid 8D 会保留在右下角通知区域；双击托盘图标可以重新打开，右键菜单可以打开或彻底退出。

升级前关闭程序，再运行安装包。案例和模型设置位于独立数据目录，升级不会主动清除。当前安装器不注册系统卸载项；移除时关闭程序，删除安装目录及快捷方式即可，案例目录可单独保留。

## 首次使用

1. 打开左下角“模型设置”。
2. 输入服务提供的接口地址、模型名称、API 密钥。支持 Chat Completions 兼容接口，可填基础地址（通常以 /v1 结尾）或完整 /chat/completions 地址。
3. 点击“保存并测试连接”。这一步只发出简短的连接测试。
4. 创建案例，选择中文或中英双语报告，然后从“引导分析”或“资料成稿”开始。

本版本没有内置模型或免费额度；模型服务使用你自己的配置。密钥不用发到此对话中。原生 Claude、Gemini 等非 Chat Completions 协议未实现；需使用支持该协议的服务或兼容网关。高级设置可调整输出上限、长度参数与 JSON 模式，需与所选服务匹配。

## 两种工作方式

**引导分析**：描述现象或补充发现，AI围绕当前阶段提出一个关键问题，给出报告建议。可随时切换 D1–D8，不需要先补全 D1 才讨论根因。

**资料成稿**：上传或粘贴整个调查过程，核对提取范围，点击“整份成稿”。AI整理 D1–D8 草稿，列出资料缺口和冲突。打开“查看建议”，选择采用哪些阶段，随后仍可逐步对话。

生成时向所选服务发送当前报告、已有分析记录和勾选的原始资料。取消勾选只排除该份原始资料；此前已经写入报告或分析记录的内容仍属于上下文。其他案例不发送。

## 编辑与复核

- 正文支持直接编辑并自动保存。AI重新生成时先显示建议对比，有手工修改的阶段默认不勾选。
- D4 提供独立的“鱼骨图与根因”视图，可编辑原因、子因、证据来源、验证状态及产生/逃逸根因记录；其他阶段不显示鱼骨入口。
- 鱼骨图展示候选原因；有支持证据不等于因果已验证。“已验证”项需要来源和验证记录或关联根因。
- 修改问题定义、鱼骨或根因会撤销相关下游阶段的复核状态。
- “阶段复核”集中确认关键检查项，不需要逐句确认。D4须有实际根因验证；D8须待前七阶段复核后才可结案。
- “历史版本”可查看和恢复旧内容，恢复前的现状也会保留。
- 阶段尚未完成时仍可导出草稿，状态、关键缺口和证据索引随报告保留。

## 文件输入与报告输出

支持 DOCX、文字型 PDF、XLSX、XLS、CSV、TSV、TXT、MD。旧版 DOC 请另存为 DOCX。扫描件、照片及文档中的图片暂不做 OCR。文件只在本机提取文字；读取限制会在资料卡片中显示。

单文件最多 20 MB；PDF最多200页；Excel每表前5000行、80列；每份资料最多提取12万字符。公式使用文件里保存的缓存值，不重新计算。模型单次案例上下文超过16万字符时会提示减少资料，不会无提示截断。

Word 可继续编辑正文和表格，鱼骨图以图片插入；图中长标签缩略，完整原因保存在紧随其后的表格。鱼骨内容请回应用编辑后重新导出。PDF嵌入中文字体，便于交付；无需本机 Word 或 LibreOffice 即可生成。中英双语正文由所选模型按逐段对照规则生成，应用的固定界面和固定报告栏目目前以中文为主。

## 数据和退出

案例数据库、原始附件、模型设置和导出文件存放于：

%LOCALAPPDATA%\Rapid8D

密钥使用当前 Windows 账户加密，不能直接复制给另一账户使用。备份案例时先退出程序，再复制上述目录；在另一台机器使用时需重新配置密钥。

导出时会下载报告，同时在数据目录 exports 中保留文件及对应案例快照。应用底部“退出”会保存编辑并停止本地服务；窗口提示已退出后关闭即可。直接关闭窗口后服务通常会在约一分钟内结束；异常关闭有额外超时检测。双击启动会复用已运行的服务。

## 本版验收范围

- 13项核心自动检查：数据版本、来源引用、根因证据、关闭条件、密钥保护、解析、长表格导出和本机接口等。
- 打包 exe 的界面逻辑检查：设置、粘贴、上传、两种分析流程、建议采用、手改保留、鱼骨、历史和导出。
- 安装包解压、文件完整性和快捷方式创建；安装后的 exe 完成 DOCX/PDF/XLSX 导入、分析、Word/PDF 导出、退出和重开持久化。
- 模拟中英报告逐页渲染检查。Word由本机 Word 文档接口渲染，PDF由 Poppler 渲染。
- 模型流程使用本机模拟服务，未用真实密钥或真实模型验收专业分析质量。新版首页已完成 1280×960 视觉检查；完整交互流程由隔离的桌面界面测试覆盖。
- 未来手机端、扫描件识别、多人协作、审批权限和专有客户模板尚未实现。

## 开发和重新打包

代码位于 rapid8d/、ui/，规则位于 prompts/，测试位于 desktop_tests/。desktop/build.ps1 构建独立目录程序，desktop/build-setup.ps1 构建安装包，desktop/build-launcher.ps1 生成根目录快捷启动器；Python 路径可通过参数指定。desktop/requirements.txt 为依赖范围，具体构建环境见 docs/desktop-validation.md。

运行核心检查：python -m unittest discover -s desktop_tests -v。界面逻辑检查依赖测试用 jsdom，并需要隔离的测试实例和模拟服务；不打入发布版。

原工作区中已经删除的旧应用文件未恢复；新实现位于上述独立目录，未提交或推送代码。
